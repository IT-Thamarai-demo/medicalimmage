## Detailed Description (For Cover Letter)
This final year project demonstrates end-to-end machine learning expertise. I built a production-ready pneumonia detection system that analyzes chest X-rays with 92% accuracy while providing explainable AI heatmaps for medical professionals.

**Technical Highlights:**
- Implemented transfer learning with EfficientNetB0 (pre-trained on ImageNet) to extract meaningful features from medical images
- Developed SVM classifier with RBF kernel to handle complex pneumonia vs. normal patterns
- Created Grad-CAM visualization to explain AI decisions—critical for medical applications where trust is essential
- Built interactive Streamlit dashboard for image upload, real-time prediction, and PDF report generation
- Deployed on free cloud infrastructure, demonstrating optimization for resource-constrained environments

**Results**: 95% sensitivity (catches pneumonia cases), 88% precision (minimizes false alarms), 2-3 second inference time per image

## Interview Answer Script
"I developed an **Explainable AI system for pneumonia detection** from chest X-rays. The project combines three key technical components:

**Architecture**: I use EfficientNetB0—a lightweight pre-trained neural network—to extract 1280 features from X-ray images. Rather than training from scratch (20+ hours), transfer learning cut training to 2 hours while maintaining 92% accuracy.

**Classification**: I chose SVM over neural networks because it handles our limited training data (5000 images) better and is more interpretable—important for medical applications.

**Explainability**: Using Grad-CAM, I generate heatmaps showing which image regions influenced the diagnosis. This is crucial because radiologists need to understand and verify AI decisions.

**Deployment**: The system runs on a Streamlit web dashboard where doctors upload images and get instant predictions with confidence scores and PDF reports.

What I'm proud of: achieving 95% sensitivity (catching pneumonia) while maintaining 88% precision (accurate predictions), and doing it all for free using Streamlit Cloud. This project taught me that building AI systems isn't just about accuracy—it's about making them trustworthy, explainable, and practically deployable."
